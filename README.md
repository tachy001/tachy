# Luxury Tree

一棵可定制的 3D 圣诞树 / 照片树，适合做节日礼物页、纪念页或个人展示页。

页面本身只是一个 `index.html`：CSS、JavaScript、材质生成、数据存储和导入导出逻辑全部内联，不需要安装依赖或构建。Three.js、MediaPipe 和字体从 CDN 加载。

## 功能

- **三套主题**：鎏金、冰蓝、芭比。标题渐变、UI 强调色、粒子材质、雪花/爱心背景一起切换。
- **照片树**：上传或拖入照片，自动压缩到最长边 1600px；素材库可预览、聚焦、删除、清空。
- **书信**：编辑后以打字机效果展示，点击可跳过打字；支持换行和 emoji。
- **背景音乐**：上传、播放/暂停、静音、音量调节、淡入。
- **摄像头手势（按需开启）**：OK 打开书信、食指聚焦、张开手掌散开、竖起大拇指或比 V 换主题。
- **鼠标 / 触摸**：拖拽旋转、滚轮或双指缩放、点击照片聚焦、双击重置视角。
- **自动保存**：标题、主题、书信、照片、音乐保存在浏览器 IndexedDB，下次打开可恢复。
- **导入 / 导出**：导出展示版或编辑版独立 HTML、导出配置 JSON；支持导入之前导出的 HTML/JSON。
- **展示模式**：隐藏编辑界面，只保留画面和退出按钮。
- **性能优化**：粒子使用 InstancedMesh 合批，雪/爱心背景使用顶点 shader，自动画质分档。
- **可访问性**：键盘 Esc/H、focus-visible、`prefers-reduced-motion`、移动端安全区与 `100dvh`。

## 文件

```text
index.html   # 页面本体，单文件
README.md    # 本说明
```

没有 `package.json`、构建脚本或本地依赖。修改后直接刷新浏览器即可。

## 快速开始

### 方式一：直接打开

双击 `index.html` 即可。注意：

- 需要联网加载 CDN 资源。
- 部分浏览器在 `file://` 下不允许使用摄像头，手势功能会不可用。
- IndexedDB 在 `file://` 下的行为因浏览器而异。

### 方式二：本地服务器（推荐）

```bash
python -m http.server 8765
```

打开：

```text
http://127.0.0.1:8765/index.html
```

摄像头手势需要 `localhost` 或 HTTPS 环境。

## 使用说明

### 主题

- 点击右侧“换主题”按钮循环切换三套主题。
- 也可以在“设置 → 主题”中直接选择。
- 开启摄像头且“手势换主题”为开启状态时，可以做 **👍 竖起大拇指** 或 **✌️ 比 V** 切换主题。
- 张开手掌是“散开”手势，不再用于换主题。

### 照片

1. 点击“素材库 → 添加照片”，或直接把图片拖进页面。
2. 最多 12 张；单张不超过 25 MB。
3. 大图会自动压缩到最长边 1600px，再存入场景和自动存档。
4. 点击缩略图可让照片在场景中聚焦；点击画布上的照片也可以聚焦。
5. 缩略图右上角的 × 可删除单张照片；“清空照片”会删除全部照片。

照片会围绕树分布，并始终面向镜头，避免侧对观众时只剩一条边。

### 书信

- “编辑书信”打开编辑框，保存后可点击“查看书信”。
- 展示时先等待约 1.8 秒，然后逐字打出；点击内容可立即显示全文。
- 按 `Esc` 或右上角 × 关闭书信。
- 书信为空时“查看书信”按钮会自动禁用。
- 摄像头开启时，OK 手势也可以打开书信（需要先有内容）。

### 音乐

- 在“素材库 → 背景音乐”中上传音频，单文件不超过 50 MB。
- 支持播放/暂停、静音、音量调节。
- 播放时会淡入音量；浏览器可能阻止自动播放，此时点击“播放”即可。
- 上传新音乐会替换旧音乐。

### 摄像头手势

1. 打开“设置”。
2. 点击“摄像头手势”右侧的“开启”。
3. 阅读手势说明，再点击“启用摄像头”，允许浏览器权限。
4. 左上角状态显示“手势已开启”；检测到手时会变为“已检测到手”。

| 手势 | 效果 |
| --- | --- |
| 👌 OK（拇指与食指捏合，中指伸展） | 打开书信 |
| ☝️ 食指指向 | 聚焦照片；没有照片时聚焦星星 |
| 🖐️ 张开手掌 | 装饰散开，并随手掌移动旋转 |
| 👍 竖起大拇指 | 切换主题 |
| ✌️ 比 V（食指 + 中指） | 切换主题 |

说明：

- 摄像头画面只在浏览器本地处理，不会上传。
- 手势换主题触发一次后需要松手才能再次触发，避免连续切换。
- “手势换主题”开关显示的是**可执行的动作**：当前开启时按钮显示“关闭”，当前关闭时按钮显示“开启”；当前状态看按钮左侧提示。
- 如果做换主题手势时功能是关闭的，页面会提示去设置中开启。
- 可在设置中随时关闭摄像头。

### 鼠标 / 触摸

- 拖拽：旋转场景（带惯性）。
- 滚轮 / 双指捏合：拉近拉远。
- 单击照片：聚焦；单击空白处或按 `Esc`：退出聚焦。
- 双击空白处：重置视角和缩放。

### 自动保存与恢复

- 自动保存的内容：标题、主题、书信、照片、音乐。
- 存储位置：浏览器 IndexedDB，数据库 `luxury-tree`，仓库 `state`，键 `current`。
- 页面有变更后约 0.7 秒写入；刷新或重新打开时会提示“检测到上次编辑的内容”，可选择恢复或忽略。
- “设置 → 清除自动存档”只清除存档，不会删除当前页面内容。
- 画质、音量、静音、手势开关保存在 localStorage，键名 `luxury-tree-settings-v1`。

### 导入 / 导出

点击“导出”会看到三个选项：

1. **展示版网页**：导出 `luxury-tree-show-*.html`，打开后直接进入展示模式，适合送给对方。
2. **编辑版网页**：导出 `luxury-tree-edit-*.html`，保留编辑按钮，适合自己继续修改。
3. **仅导出配置 JSON**：导出 `luxury-tree-*.json`，用于备份或再次导入。

导出的 HTML 会内嵌照片、音乐和配置，可以直接双击打开或分享。但它仍然需要联网加载 Three.js / MediaPipe / 字体。

导入支持 `.json` 和本页面导出的 `.html`。也可以把图片、音频、JSON/HTML 直接拖进页面。

配置文件大致结构：

```json
{
  "version": 3,
  "title": "标题",
  "letter": "书信内容",
  "theme": 0,
  "photos": [
    { "src": "data:image/jpeg;base64,...", "name": "photo.jpg" }
  ],
  "music": "data:audio/mpeg;base64,...",
  "musicName": "music.mp3",
  "isGestureSwitchEnabled": true
}
```

主题编号：`0` 鎏金，`1` 冰蓝，`2` 芭比。

### 展示模式

- 点击“展示模式”隐藏编辑界面，并尝试进入全屏。
- 底部会显示低透明度的“退出展示 Esc”。
- 按 `Esc` 或点击该按钮退出展示模式；退出时也会退出全屏。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `Esc` | 依次关闭确认框、弹窗、书信、抽屉、展示模式、聚焦，最后恢复隐藏的界面 |
| `H` | 隐藏 / 恢复界面（输入框内不生效） |

隐藏界面后，点击画面任意位置即可恢复。

### 画质

“设置 → 画质”提供自动、高、中、低四档：

| 档位 | 粒子数 | 尘埃 | 雪 / 爱心 | 像素比 | Bloom |
| --- | ---: | ---: | ---: | ---: | --- |
| 高 | 1800 | 1500 | 2500 / 1500 | 1.5 | 开 |
| 中 | 1200 | 900 | 1800 / 1200 | 1.25 | 开 |
| 低 | 700 | 450 | 1000 / 800 | 1.0 | 关 |
| 自动 | 按设备选择 | | | | |

切换画质会重建粒子，可能需要约 1 秒。

## 依赖

页面从以下 CDN 加载资源：

- Three.js `0.160.0`（`cdn.jsdelivr.net`）
- MediaPipe Tasks Vision `0.10.3`（`cdn.jsdelivr.net`）
- 手势模型（`storage.googleapis.com`）
- Google Fonts：Cinzel、Ma Shan Zheng

没有做依赖本地化，因此离线或 CDN 被拦截时页面无法完整启动，加载页会显示失败提示。

## 浏览器要求

- 支持 WebGL 的现代浏览器（Chrome、Edge、Safari、Firefox 近期版本）。
- 手势需要 `getUserMedia`，且页面运行在 `localhost` 或 HTTPS。
- 自动保存需要 IndexedDB。
- 全屏、摄像头、自动播放都受浏览器权限策略影响。
- 移动端建议使用较新的 Safari / Chrome，并在“设置”中选择较低画质。

## 常见问题

**手势没有反应**

- 确认设置中“摄像头手势”已开启，左上角状态显示“手势已开启”。
- 确认“手势换主题”为开启状态（看提示文字，不要只看按钮文字）。
- 手要完整出现在画面中；光线不足或手离镜头太远会影响识别。
- 换主题优先试 ✌️ V 手势，通常比大拇指更容易识别。
- 关闭再重新开启摄像头可重置识别状态。

**页面一直转圈或显示加载失败**

- 检查网络能否访问 `cdn.jsdelivr.net` 和 `storage.googleapis.com`。
- 换一个网络或使用代理后刷新。

**刷新后没有提示恢复**

- 可能使用了无痕模式、清除了站点数据，或自动存档被手动清除。
- 换浏览器或换域名不会共享 IndexedDB。

**音乐没有自动播放**

- 浏览器自动播放策略会阻止无交互播放；点击素材库里的“播放”即可。

**导出的 HTML 打不开 / 没有画面**

- 导出的 HTML 仍需要联网加载 CDN。
- 文件可能过大，部分聊天软件会压缩或拒绝；可以改用“仅导出配置 JSON”。

**照片模糊**

- 上传时超过 1600px 的图片会被压缩，这是为了控制显存和导出体积。
- 如果需要更高清晰度，可在 `CONFIG.photo.maxSize` 中调大后再使用。

## 开发说明

页面没有构建步骤，直接编辑 `index.html`：

- `<style>`：全部样式、主题变量、响应式布局。
- `<script type="module">`：Three.js 场景、粒子、照片、手势、存储、导入导出。
- `CONFIG`：相机、粒子数、手势阈值、照片限制、画质档。
- `THEMES`：主题名称、颜色、材质映射、背景类型。
- `STATE`：运行时状态。

浏览器控制台可通过 `window.__LUXURY_TREE__` 调试：

```js
__LUXURY_TREE__.state          // 运行时状态
__LUXURY_TREE__.switchTheme(1) // 切换主题
__LUXURY_TREE__.applyQuality('low')
__LUXURY_TREE__.serializeScene()
```

注意：修改内联脚本时要保持只有一个 `<script type="module">`，且不要引入本地文件引用，否则会破坏“单文件”特性。
